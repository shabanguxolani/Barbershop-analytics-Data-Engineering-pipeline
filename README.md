# Barbershop-analytics-Data-Engineering-pipeline

## Project Goal

The goal of this project is to build an end-to-end data engineering pipeline that transforms raw barbershop CSV data into a structured data warehouse for business analytics and reporting in Power BI.

## Tech Stack

- SQL Server
- Python
- Power BI
- Git & GitHub

## Pipeline Flow

CSV Files -> Bronze Layer -> Staging Layer -> Data Warehouse -> Power BI Dashboard
